Real jcode, running in a GitHub Codespace only while you use it. Your code lives in this repository.

▶ Start / Resume jcode Manage / stop running codespaces Save Gemini key (secret GEMINI_API_KEY) & idle timeout
  1. Tap Start — first launch takes ~2–3 min, later resumes are fast.
  2. In the terminal type jcode.
  3. No secret saved? Run jcode login --provider gemini.
  4. Push your work with git, then close the tab. It auto-stops when idle.
