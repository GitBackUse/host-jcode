# Host JCode — quick start
1. Open the terminal (Ctrl+`) and type `jcode`.
2. First time: `jcode login --provider gemini` and paste your Gemini key
   (or save it once as a Codespaces secret named GEMINI_API_KEY).
3. Save work: `git add -A && git commit -m "work" && git push`.
4. Close the tab when done — the codespace stops by itself when idle.
